> **관련 문서**: [설계 명세서](./group_dm_spec.md)  
> **브랜치**: `occm-groupdm`  
> **최종 수정**: 2025-01  
> **상태**: Draft

## 1. 디자인 방향

### 1.1 레퍼런스

트위터(X) DM UI를 주요 레퍼런스로 삼아 다음 특성을 반영한다:

- 2-패널 레이아웃 (대화방 목록 + 메시지 뷰)
- 말풍선(Chat Bubble) 기반 메시지 표시
- 실시간 미읽 표시 (사이드바 빨간점)
- 깔끔하고 집중할 수 있는 대화 인터페이스

### 1.2 디자인 원칙

1. **일관성**: 기존 마스토돈 UI의 컬러 팔레트, 폰트, 아이콘 체계를 준수한다.
2. **접근성**: WCAG 2.1 AA 수준의 대비 비율, 키보드 네비게이션, 스크린 리더 지원.
3. **반응형**: 데스크탑(2-패널)과 모바일(단일 패널 전환) 모두 최적의 경험을 제공한다.
4. **최소주의**: 불필요한 장식을 배제하고 콘텐츠(대화)에 집중한다.

## 2. 전체 레이아웃

### 2.1 데스크탑 (768px 이상)

```
+-------+---------------------------+-----------------------------+
| 사이드 |   좌측 패널 (350px)        |   우측 패널 (나머지)          |
| 바     |   대화방 목록              |   메시지 뷰                  |
|       |                           |                             |
| [홈]   | [검색바]  [새 메시지 +]    | [헤더: 대화방 정보]           |
| [알림] | +-----------------------+ | +-------------------------+ |
| [DM●] | | 아바타 | 이름      시간 | | |  상대 메시지 (좌측)       | |
| [검색] | |       | 미리보기   ●  | | |          내 메시지 (우측) | |
| [...]  | +-----------------------+ | |  상대 메시지 (좌측)       | |
|       | | 아바타 | 이름      시간 | | |          내 메시지 (우측) | |
|       | |       | 미리보기      | | +-------------------------+ |
|       | +-----------------------+ | [이모지] [첨부] [입력] [전송] |
+-------+---------------------------+-----------------------------+
```

**비율 및 크기:**
- 사이드바: 기존 마스토돈 사이드바 너비 유지 (약 70px 축소형, 280px 확장형)
- 좌측 패널: 고정 너비 350px
- 우측 패널: 나머지 영역 자동 확장 (최소 400px)
- 전체 최소 높이: 뷰포트 100vh (사이드바 제외 영역)

### 2.2 모바일 (768px 미만)

```
상태 1: 대화방 목록 전체 화면
+-------------------------------+
| [뒤로] 메시지 [새 메시지 +]     |
+-------------------------------+
| [검색바]                       |
+-------------------------------+
| 아바타 | 이름          시간    |
|       | 마지막 메시지..   ●   |
+-------------------------------+
| 아바타 | 이름          시간    |
|       | 마지막 메시지..       |
+-------------------------------+

상태 2: 메시지 뷰 전체 화면 (대화방 선택 시)
+-------------------------------+
| [< 뒤로] 대화방 이름  [설정]    |
+-------------------------------+
|                               |
|   상대 메시지 (좌측 말풍선)     |
|           내 메시지 (우측)     |
|   상대 메시지 (좌측 말풍선)     |
|                               |
+-------------------------------+
| [이모지][첨부] [입력...]  [>]  |
+-------------------------------+
```

**전환 방식:**
- 대화방 목록에서 항목 탭 -> 메시지 뷰로 슬라이드 전환
- 메시지 뷰에서 "뒤로" 버튼 -> 대화방 목록으로 복귀
- 브라우저 뒤로가기도 동일하게 동작 (History API 연동)

## 3. 컴포넌트 상세 디자인

### 3.1 대화방 목록 (ChatRoomList)

#### 헤더 영역

| 요소 | 스타일 |
|------|--------|
| 제목 "메시지" | 기존 column-header 스타일 적용, font-weight: 700, font-size: 16px |
| "새 메시지" 버튼 | 우측 배치, 아이콘 버튼 (연필+종이 아이콘), hover 시 배경 하이라이트 |
| 검색바 | 헤더 아래, 둥근 모서리(border-radius: 20px), placeholder: "대화 검색..." |

#### 대화방 항목 (ChatRoomItem)

```
+--+------------------------------------------+
|  |  이름                           3분 전    |
|아| 마지막 메시지 미리보기 텍스트...    ●       |
|  |                                          |
+--+------------------------------------------+
```

**레이아웃:**
- 높이: 72px
- 좌측 패딩: 16px
- 아바타 크기: 48px (1:1), 40px x 2개 겹침 (그룹)
- 텍스트 영역: 아바타 우측 12px 간격
- 이름: font-weight: 600, font-size: 15px, 1줄 ellipsis
- 미리보기: font-size: 14px, color: secondary-text, 1줄 ellipsis
- 시간: font-size: 13px, color: secondary-text, 우측 정렬
- 미읽 표시: 빨간 원형 점 (8px), 시간 아래 우측

**상태별 스타일:**
- 기본: 배경 투명
- Hover: 배경 rgba(255,255,255,0.05) (다크 모드) / rgba(0,0,0,0.03) (라이트 모드)
- 선택됨(active): 배경 rgba(29,155,240,0.1), 좌측 3px 파란 보더
- 미읽: 이름 font-weight: 700, 미리보기 color: primary-text

#### 그룹 대화방 아바타

- 2명: 2개의 아바타를 대각선으로 겹쳐서 배치 (우하단 아바타 75% 크기)
- 3명: 상단 1개 + 하단 2개 격자 배치
- 4명 이상: 2x2 격자 배치 (최대 4개)

### 3.2 메시지 뷰 (ChatRoomView)

#### 헤더 (ChatRoomHeader)

```
+--+------------------------------------------+--+
|아|  이름 (온라인 상태)                        |⚙ |
|  |  참여자 N명                               |  |
+--+------------------------------------------+--+
```

**레이아웃:**
- 높이: 56px
- 배경: 기존 column-header와 동일
- 좌측: 아바타 (36px) + 이름/참여자수
- 우측: 설정 아이콘 (기어 또는 점 3개)

#### 메시지 영역

**스크롤 동작:**
- 하단에서 시작 (최신 메시지가 하단)
- 위로 스크롤 시 이전 메시지 무한 로드 (intersection observer)
- 새 메시지 수신 시: 하단에 있으면 자동 스크롤, 위에 있으면 "새 메시지" 플로팅 버튼 표시

**날짜 구분선:**
- 날짜가 바뀌면 메시지 사이에 구분선 삽입
- 스타일: 가로 선 + 중앙에 날짜 텍스트 (예: "2025년 1월 15일")
- font-size: 13px, color: secondary-text

#### 메시지 말풍선 (MessageItem)

**내 메시지 (우측 정렬):**
```
                           +------------------+
                           | 메시지 내용       |
                           | 텍스트           |
                           +------------------+
                                    12:30 ✓
```

- 정렬: 우측 (margin-left: auto)
- 배경: #1d9bf0 (마스토돈 브랜드 블루) / 다크모드: #1a8cd8
- 텍스트: #ffffff
- border-radius: 18px 18px 4px 18px (우하단만 작게)
- 최대 너비: 75%
- 패딩: 10px 14px
- 시간: 메시지 아래 우측, font-size: 12px, color: secondary-text

**상대 메시지 (좌측 정렬):**
```
+--+ +------------------+
|아| | 메시지 내용       |
+--+ | 텍스트           |
     +------------------+
이름  12:30
```

- 정렬: 좌측
- 아바타: 24px, 메시지 좌측
- 배경: #2f3336 (다크모드) / #eff3f4 (라이트모드)
- 텍스트: 기본 텍스트 색상
- border-radius: 18px 18px 18px 4px (좌하단만 작게)
- 최대 너비: 75%
- 패딩: 10px 14px
- 발신자 이름: 그룹 대화방에서만 표시, font-size: 13px, font-weight: 600
- 시간: 메시지 아래 좌측, font-size: 12px

**연속 메시지 (같은 사람이 연속으로 보낸 경우):**
- 아바타 숨김 (동일 여백 유지)
- 이름 숨김
- 말풍선 간격 축소: 2px (기본 8px)
- border-radius 변경: 모두 4px (연결감 표현)

#### 첨부파일 표시

- 이미지: 메시지 말풍선 내부, 최대 너비 100%, border-radius: 12px
- 다중 이미지: 2x2 격자 배치, gap: 2px
- 동영상: 썸네일 + 재생 아이콘 오버레이
- 파일: 아이콘 + 파일명 + 크기 (다운로드 링크)

### 3.3 메시지 입력 영역 (MessageCompose)

```
+--+--+----------------------------------------+--+
|😀|📎| 메시지를 입력하세요...                    |➤ |
+--+--+----------------------------------------+--+
```

**레이아웃:**
- 높이: 최소 52px, 입력 내용에 따라 최대 150px까지 확장
- 배경: 약간 다른 배경색 (구분용)
- 하단 border-top: 1px solid divider-color

**구성 요소:**
| 요소 | 크기 | 위치 | 동작 |
|------|------|------|------|
| 이모지 버튼 | 32px | 좌측 | 클릭 시 이모지 피커 팝업 |
| 첨부 버튼 | 32px | 이모지 우측 | 클릭 시 파일 선택 다이얼로그 |
| 텍스트 입력 | 자동 확장 | 중앙 | 여러 줄 지원, Enter로 전송, Shift+Enter로 줄바꿈 |
| 전송 버튼 | 32px | 우측 | 텍스트 입력 시에만 활성화, 파란색 |

**첨부 미리보기:**
- 텍스트 입력 위에 가로 스크롤 가능한 썸네일 목록
- 각 썸네일: 80px x 80px, border-radius: 8px
- 삭제 버튼: 썸네일 우상단 X 아이콘

### 3.4 새 대화방 생성 모달 (NewChatRoomModal)

```
+------------------------------------------+
|  [X] 새 메시지                            |
+------------------------------------------+
| 받는 사람: [사용자 검색 입력]              |
|                                          |
| +------+ +------+ +------+              |
| |@user1| |@user2| |@user3|  (선택된 태그) |
| +------+ +------+ +------+              |
|                                          |
| [검색 결과 목록]                          |
| +--------------------------------------+ |
| | 아바타 | 이름 (@handle)              | |
| +--------------------------------------+ |
| | 아바타 | 이름 (@handle)              | |
| +--------------------------------------+ |
|                                          |
| [대화 시작] 버튼                          |
+------------------------------------------+
```

**동작 흐름:**
1. "새 메시지" 버튼 클릭 -> 모달 표시
2. 사용자 검색 입력 -> 자동완성 결과 표시
3. 사용자 선택 -> 태그 형태로 상단에 추가
4. 2명 이상 선택 시 "그룹 이름" 입력 필드 추가 표시
5. "대화 시작" 클릭 -> 대화방 생성 + 해당 대화방으로 이동

## 4. 알림 UI

### 4.1 사이드바 배지 (빨간점)

```
[메시지 아이콘] ●
```

- 위치: 사이드바 "메시지" 메뉴 항목의 아이콘 우상단
- 크기: 8px 원형
- 색상: #ff3b30 (시스템 레드)
- 조건: `unread_count > 0`일 때 표시
- 애니메이션: 새 메시지 수신 시 잠시 scale 팝 효과 (0.8 -> 1.2 -> 1.0, 300ms)

### 4.2 사운드 알림

- 트리거: `dm_message` 스트리밍 이벤트 수신 && 현재 보고 있는 대화방이 아닌 경우
- 사운드: 짧은 알림음 (기존 마스토돈 알림 사운드와 다른 톤)
- 설정: 사용자가 DM 사운드 알림 on/off 가능 (기본: on)

### 4.3 브라우저 Push 알림

- 제목: "[발신자 이름]님의 메시지"
- 본문: 메시지 미리보기 (최대 60자)
- 아이콘: 발신자 아바타
- 클릭 시: 해당 대화방으로 이동

## 5. 인터랙션 패턴

### 5.1 메시지 전송

| 단계 | 동작 | UI 반응 |
|------|------|---------|
| 1 | 텍스트 입력 | 전송 버튼 활성화 (회색 -> 파란색) |
| 2 | Enter 또는 전송 버튼 클릭 | 입력 영역 초기화 |
| 3 | 전송 중 | 메시지 말풍선 즉시 표시 (낙관적 업데이트), 투명도 50% |
| 4 | 전송 성공 | 투명도 100%로 전환 |
| 5 | 전송 실패 | 빨간 경고 아이콘 + "재전송" 버튼 표시 |

### 5.2 메시지 로딩

| 단계 | 동작 | UI 반응 |
|------|------|---------|
| 1 | 대화방 최초 진입 | 스켈레톤 로딩 (말풍선 형태의 회색 플레이스홀더) |
| 2 | 메시지 로드 완료 | 스켈레톤 -> 실제 메시지 교체, 하단으로 스크롤 |
| 3 | 위로 스크롤 (이전 메시지) | 상단에 로딩 스피너, 완료 시 스크롤 위치 유지 |

### 5.3 대화방 전환

| 단계 | 동작 | UI 반응 |
|------|------|---------|
| 1 | 대화방 목록에서 항목 클릭 | 해당 항목 active 상태로 변경 |
| 2 | 우측 패널 전환 | 이전 대화방 메시지 fade out, 새 대화방 로딩 |
| 3 | 미읽 대화방 진입 | 자동으로 read API 호출, 빨간점 제거 |

### 5.4 메시지 삭제

- 본인 메시지 길게 누르기(모바일) 또는 hover 시 "..." 메뉴 표시
- "삭제" 선택 -> 확인 다이얼로그 -> 삭제 후 메시지 영역에서 제거
- 상대방 화면에서는 "삭제된 메시지입니다" 텍스트로 교체 (회색 이탤릭)

### 5.5 스크롤 동작

- 새 메시지 수신 시:
  - 현재 스크롤이 하단에 있으면: 자동으로 아래로 스크롤
  - 현재 스크롤이 위에 있으면: 하단에 "N개의 새 메시지" 플로팅 버튼 표시
  - 플로팅 버튼 클릭: 하단으로 부드럽게 스크롤

## 8. 애니메이션 및 트랜지션

### 8.1 메시지 등장

- 새 메시지 표시: slide-up + fade-in (200ms, ease-out)
- 낙관적 업데이트 메시지 확정: opacity 0.5 -> 1.0 (150ms)

### 8.2 대화방 목록 업데이트

- 새 메시지로 대화방 순서 변경: 해당 항목이 상단으로 이동 (300ms, ease-in-out)
- 새 대화방 추가: fade-in + slide-down (200ms)

### 8.3 패널 전환 (모바일)

- 목록 -> 메시지 뷰: slide-left (250ms, ease-out)
- 메시지 뷰 -> 목록: slide-right (250ms, ease-out)

### 8.4 미읽 배지

- 등장: scale 0 -> 1.2 -> 1.0 (300ms, spring)
- 제거: scale 1.0 -> 0 (200ms, ease-in)

## 10. 에러 상태

### 10.1 메시지 전송 실패

- 해당 메시지 말풍선에 빨간 테두리 표시
- 우측에 경고 아이콘 (⚠)
- 탭/클릭 시 "재전송 | 삭제" 옵션 표시

### 10.2 네트워크 오류

- 메시지 영역 상단에 배너: "네트워크에 연결할 수 없습니다. 재연결 중..."
- 배경: #ff9500 (경고 오렌지)
- 재연결 성공 시 자동으로 사라짐 (fade-out)

### 10.3 대화방 로딩 실패

- "대화를 불러올 수 없습니다" 텍스트 + "다시 시도" 버튼
- 중앙 정렬

## 11. 접근성 (Accessibility)

### 11.1 키보드 네비게이션

| 키 | 동작 |
|----|------|
| Tab | 대화방 목록 -> 메시지 영역 -> 입력 영역 순서로 포커스 이동 |
| Enter | 대화방 선택 / 메시지 전송 |
| Shift+Enter | 메시지 내 줄바꿈 |
| Escape | 모달 닫기 / 검색 취소 |
| Arrow Up/Down | 대화방 목록 내 이동 |

### 11.2 ARIA 속성

```html
<!-- 대화방 목록 -->
<nav role="navigation" aria-label="대화방 목록">
  <ul role="listbox" aria-label="대화 목록">
    <li role="option" aria-selected="true" aria-label="User A와의 대화, 미읽 메시지 있음">

<!-- 메시지 영역 -->
<main role="log" aria-label="메시지 내역" aria-live="polite">
  <article role="article" aria-label="User A: 안녕하세요, 오후 3시 30분">

<!-- 입력 영역 -->
<form role="form" aria-label="메시지 작성">
  <textarea aria-label="메시지 입력" aria-placeholder="메시지를 입력하세요...">
```

### 11.3 스크린 리더 지원

- 새 메시지 수신 시 `aria-live="polite"` 영역에 알림
- 미읽 카운트 변경 시 사이드바 링크의 `aria-label` 업데이트
- 이미지 첨부파일에 대한 alt 텍스트 지원

## 12. 반응형 브레이크포인트

| 브레이크포인트 | 레이아웃 |
|--------------|----------|
| >= 1200px | 사이드바(확장) + 좌측 패널(350px) + 우측 패널(나머지) |
| 768px ~ 1199px | 사이드바(축소) + 좌측 패널(300px) + 우측 패널(나머지) |
| < 768px | 단일 패널 (목록/메시지 뷰 전환) |

### 모바일 추가 고려사항

- 터치 영역 최소 44px x 44px
- 스와이프 제스처: 우측 스와이프로 뒤로가기 (iOS 관례)
- 키보드 올라올 때 입력 영역이 가려지지 않도록 viewport 조정
- 가로 모드에서도 정상 동작

기존 마스토돈의 테마 시스템을 따른다. CSS 변수를 활용하여 테마 전환 시 자동 대응:

```scss
// styles/dm.scss
.dm-panel {
  background: var(--background-color);
  border-color: var(--border-color);
}

.message-bubble--own {
  background: var(--dm-own-message-bg, #1d9bf0);
  color: var(--dm-own-message-text, #ffffff);
}

.message-bubble--other {
  background: var(--dm-other-message-bg);
  color: var(--dm-other-message-text);
}

// 테마별 변수 정의
:root {
  --dm-own-message-bg: #1d9bf0;
  --dm-own-message-text: #ffffff;
  --dm-other-message-bg: #eff3f4;
  --dm-other-message-text: #0f1419;
}

.theme-mastodon-light {
  --dm-other-message-bg: #eff3f4;
  --dm-other-message-text: #0f1419;
}

.theme-mastodon-dark {
  --dm-other-message-bg: #2f3336;
  --dm-other-message-text: #e7e9ea;
}
```
